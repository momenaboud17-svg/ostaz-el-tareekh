# منصة أستاذ التاريخ

موقع تجريبي لمستر **بيشوي بشرا**، مدرّس التاريخ للثانوي العام والبكالوريا المصرية.

التصميم عربي (من اليمين لليسار)، بألوان الكحلي والذهبي، ويضم:

- صفحة ترحيب
- تعريف بالمدرّس
- الكورسات والمراحل
- أسباب اختيار المدرّس
- نموذج حجز تجريبي (يُحفظ في المتصفح فقط)

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح `http://127.0.0.1:8080`.
